# Portfólio | Mariza Rocha

Site estático (HTML, CSS e JavaScript puros) com visual hacker dos anos 80.

## Estrutura
- `index.html`: conteúdo e seções (Sobre Mim, Educação e Idiomas, Portfólio, Contato)
- `css/style.css`: estilos (cores nas variáveis `--g`, `--gd`, `--dim`)
- `js/main.js`: navegação entre seções e animação de boot
- `assets/`: currículo em PDF
